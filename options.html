Trilium Inbox Saver — Settings

Each profile has its own server URL, ETAPI token, and inbox note. The profile selected here is the one new saves go to; you can also switch profiles from the Web2Trilium panel.
Default for Trilium Desktop is http://localhost:37840
Trilium → Options → ETAPI → Create new ETAPI token
Right-click your Inbox note in Trilium → "Copy note ID to clipboard", and paste it here. Or click "Auto-detect" below if your Inbox note has the #inbox label (Trilium sets this by default on the note you've configured as inbox in Options → Other).
